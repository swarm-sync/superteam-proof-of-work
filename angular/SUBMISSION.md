# Bounty Tracker — Angular 20

## Suggested Superteam ADD-form title (≤ 80 chars)

Bounty Tracker — Angular 20 app with signals, routing & reactive forms

## Description

A full Angular 20 bounty tracker for the Solana ecosystem: lazy-loaded
routes (dashboard, list, detail, post-a-bounty), a signal-backed store with
computed dashboard stats, HttpClient loading seed data from a local mock
API, and a reactive form with custom validators (future-date deadline,
positive reward). Includes Karma/Jasmine unit tests for the service,
validators, and model helpers, and a production build that passes clean.
