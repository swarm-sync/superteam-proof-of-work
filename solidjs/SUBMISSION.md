# Superteam Earn — Proof-of-Work Submission (SolidJS)

## Suggested ADD-form title (76 chars)

Solana Ecosystem Explorer — SolidJS bento, springs, tactile micro-tools

## Description

An interactive Solana ecosystem explorer built in SolidJS + Vite: a 12-column
asymmetrical bento dashboard with live-feeling network telemetry animated by a
hand-rolled spring integrator, three working micro-tools (transaction fee
calculator, staking yield estimator, SOL⇄USD converter), and an explorable grid
of 12 real Solana flagship projects with category filters, favorites, and
spring-animated detail panels. Finished in the Stella design system — cursor
spotlights, razor borders, synthesized Web Audio clicks with haptics and a
global mute toggle, and full prefers-reduced-motion support. Zero runtime
dependencies beyond solid-js; builds clean and runs on `npm run dev`.
