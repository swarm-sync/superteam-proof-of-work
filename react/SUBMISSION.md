# Superteam Earn — Proof of Work Submission

## Suggested ADD-form title (63 chars)

Solana Bounty Tracker — Accessible React + TypeScript Dashboard

## Description

A polished, accessible React + TypeScript dashboard for tracking Solana
bounties: sortable/filterable data table, detail view with focus management,
Context + reducer state, debounced search, persisted bookmarks, an error
boundary, and Tailwind styling that is responsive from mobile to desktop.
Built to WCAG 2.1 AA with full keyboard support (arrow-key row navigation,
Escape to close) and 23 passing Vitest + Testing Library tests covering
filtering, sorting, formatting, and the full user flow.

## Skills

React, TypeScript, Tailwind CSS, Accessibility (WCAG 2.1 AA), Vitest,
Testing Library, Vite

## How to run

```bash
cd react
npm install
npm run dev     # http://localhost:5173
npm test        # 23 tests
npm run build   # production build
```
