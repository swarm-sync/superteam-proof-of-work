# SUBMISSION — Vue

- **Suggested ADD-form title (67 chars):** Accessible Solana Grant Wizard — Vue 3 Composition API, 4-step form
- **Description:** A four-step Solana grant application wizard built with Vue 3 Composition API and Vite: a useWizard state-machine composable with per-step validation guards, a useDraft composable that autosaves to localStorage, typed props on every component, and a reusable Field component wiring aria-invalid and aria-describedby. Step changes move focus to the new heading, validation failures focus an error summary, and the stepper and progressbar are fully announced to screen readers. Five Vitest tests cover the validation logic; production JS is 85 kB (33 kB gzip). Demo only — no data leaves the browser.
