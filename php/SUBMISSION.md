# Bounty API — Plain PHP 8 REST API, no framework

## Suggested Superteam ADD-form title (≤ 80 chars)

Bounty REST API — plain PHP 8, PDO/SQLite, router, validation & tests

## Description

A dependency-free PHP 8 REST API for bounty listings: hand-rolled router
with {param} matching, CRUD with correct HTTP codes (201/204/400/404/405),
per-field JSON validation errors, filtering and pagination, and SQLite
persistence via PDO prepared statements. Includes a 29-assertion plain-PHP
test suite that runs the real router in-process against a throwaway
database — no PHPUnit or Composer needed.
