## Suggested title (71 chars)

Solforge — Complete Brand Identity Kit for a Solana Dev-Tooling Startup

## Description

Designed a complete, original brand identity for Solforge, a fictional Solana
developer-tooling startup: a hand-crafted SVG logo system (8 lockups including
primary, horizontal, monochrome, reversed, favicon and app icon, with a
path-only geometric wordmark), an 8-token color system with measured WCAG
contrast ratios, a 3-family typography scale, and 4 applied assets (X banner,
bounty card, title slide, social post) plus palette and type specimen sheets —
all built with a reproducible Python/cairosvg pipeline and verified file by file.
